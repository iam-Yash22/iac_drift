BLOCKING ISSUE
═════════════════════════════════════════════════════════════════════════════

Error: InvalidClientTokenId: 
  "Failed to assume role: InvalidClientTokenId. Verify role_arn and credentials."

Root Cause:
  The assume_role() function needs base AWS credentials to call the STS API.
  These credentials are not present in the .env file.

  assume_role() tries to:
  1. Read AWS_ACCESS_KEY_ID from environment
  2. Read AWS_SECRET_ACCESS_KEY from environment
  3. Call: boto3.sts.assume_role()
  4. If credentials missing or invalid → InvalidClientTokenId error

Current State:
  ├─ CLOUD__AWS_ACCESS_KEY_ID: NOT SET ✗
  ├─ CLOUD__AWS_SECRET_ACCESS_KEY: NOT SET ✗
  └─ CLOUD__PROVIDER: aws ✓
